**우선순위 예외**
- RS-2~5 중 RS-6~8이 생기면 RS-2~5 해제 뒤에 표시. 오류 안내 다이얼로그는 바로 띄운다
- 원격 제어(RS-9) 중 RS-2~8 발생 → 원격 제어 자동 종료, 그 상태 해제 후 스케줄 운영 규칙. 오프라인(RS-1)은 원격 제어 유지(재부팅 · 강제 종료였으면 해제)

**정지 중 충전소 대기**: 일시정지 · 비상정지 상태는 그대로 두고 배터리만 자동 관리(80% 미만 충전 → 100% 도킹 해제). 칩은 정지 상태로 표시하고 충전 중으로 바꾸지 않는다

### 상태 전환 규칙
- UI 비상정지(RS-4) 해제 → 이전 상태와 관계없이 **일시정지(RS-5)**
- 일시정지 해제(주행 재개) → 스케줄 자율 운영(RS-13), 이후 스케줄 운영 규칙
- 상태 복귀 뒤 **스케줄 운영 규칙** (위에서부터 판단)
  1. 배터리 부족으로 충전 중이었으면 → 80%까지 충전
  2. 배터리 X% 미만 → 복귀 → 80%까지 충전
  3. 사용자 설정 대기 시간 → 복귀 → 대기
  4. 주행할 코스 있음 → 멈춘 지점부터 주행
  5. 없음 → 대기
- 해제 후 복귀 상태 (요약)
  - 스케줄 자율 운영 · 대기 중 · 충전 중 · 복귀 중 · 일시정지 · UI 비상정지에서 물리 비상정지 · 수동 제어 · 오류 · 오프라인이 생기면 → 해제 후 **이전 상태**
  - 위 상태에서 UI 비상정지가 생기면 → 해제 시 일시정지 → 다시 해제하면 이전 상태 (일시정지였으면 일시정지 유지)
  - 원격 제어 · 자율 운영 중이었으면 → 해제 후 **스케줄 운영 규칙** (오프라인만 원격 제어 유지, 재부팅 · 강제 종료였으면 해제)
- 재부팅 · 강제 종료 후 켜짐 = 오프라인에서 복귀한 것과 같게 처리 (원격 제어 · 자율 운영이었으면 해제)
- 위치 확인 중(RS-10): 5분 안에 위치를 찾으면 하던 상태를 이어감, 5분 지나면 위치 초기화 필요
- 수동 도킹 필요(DG-4)가 떠도 상태는 바뀌지 않는다
- 비상정지 + 오프라인: UI 비상정지 후 오프라인 → 비상 해제 후 온라인이 되면 일시정지 / 비상정지 시작 · 해제가 모두 오프라인 중이면 온라인 시 자율 운영

**로봇 패널 버튼 비활성 (투명도 30%)**

| 현재 상태 | 비활성 |
|---|---|
| 물리 비상정지 · UI 비상정지 · 수동 제어 | 일시정지 · 충전소 복귀 · 원격 제어 |
| 일시정지 | 원격 제어 |
| 충전소 복귀 | 일시정지 · 원격 제어 |
| 대기 중 | 원격 제어 버튼은 활성, 누르면 불가 다이얼로그 |
| 충전 중 | 원격 제어 활성. 배터리 X+20% 미만이면 누를 때 불가 다이얼로그 |

## 6. NG 그룹 · 조치 상태 (v2.2 신설, 11.27)

- **NG 그룹**: 같은 웨이포인트(진단 대상 · 진단 항목)에서 그룹이 닫히기 전까지 반복 발생한 진단 기록 묶음. NG 1건이면 그룹이 아니다(단건 NG)
- 조치 상태는 그룹이 공유하고, 바꾸면 그룹 안 모든 진단에 일괄 적용
- 그룹 안 정상 기록: NG와 똑같이 조치 기록 · 이상 발생 기록을 보여 준다. 재검사 정상 ON이면 상태 '재검사 정상'(변경 불가), OFF면 그룹 상태 공유(변경 가능)
- 그룹이 없는 기록: 단건 NG는 자기 조치 상태, 정상은 '-'

| '재검사 정상 시 자동 종료' | ON (기본값) | OFF |
|---|---|---|
| 그룹 종료 | 재검사 정상 또는 조치 완료 | 조치 완료만 |
| 그룹 구성 | NG + 진단 실패 + 그룹을 닫은 마지막 정상 | NG + 진단 실패 + 정상 |
| NG → 정상 → NG | 정상에서 닫히고 다음 NG는 새 그룹 | 같은 그룹 |

- 설정: 고객사 관리자 화면, **플랜트 단위**, 기본 ON, 변경 로그 없음
- 진단 실패는 그룹을 닫지 않고 위험도 계산에서 빠진다. 결과 비교(AL-18 · 19, 소급 판단)에서 진단 실패는 건너뛰고 그 앞 결과와 비교
- 재검사 정상으로 닫힌 그룹은 조치 상태 변경 불가
- **OFF → ON (소급 종료)**: 열린 그룹(조치 필요 · 조치 중) 중 마지막 기록이 정상인 그룹만 닫는다. 저장 전 확인 다이얼로그(대상 0건이면 생략). 조치 중이던 그룹은 마지막 조치 중 처리자에게 AL-10을 건별 발송
- **ON → OFF**: 다이얼로그 없이 저장, 닫힌 그룹은 다시 열지 않음
- 자동 종료 기록: ON 중 정상 → 종료 시각 = 정상 검사 시각, 문구 "재검사에서 정상으로 확인되어 자동 종료 처리" / 소급 → 종료 시각 = 설정 변경 시각, 문구 "재검사 정상 설정이 켜져 자동 종료 처리"(가안)
- 표시 기준
  - 맵 마커 색 · NG 카운트: **그룹 최고 위험도**(최근 결과로 바꾸지 않음), 카운트는 그룹당 1건
  - 인디케이터: 신규 NG, 그룹 최고 위험도 상승 시에만
  - 진단 내역 조치 상태 칼럼: 그 진단이 속한 그룹의 상태
- 관련: PX-124(재검사 정상 시 자동 종료), PX-127, 화면 HST-011-21 · HST-022

**서비스 기능**: 일반 사용자도 조치 상태 변경 · 진단 내역 다운로드 · 보고서 저장 · 인쇄 · 이메일 · **비상 정지 · 비상 해제** 가능. 일시 정지 · 충전소 복귀 · 수동 조작 · 주행 취소 · 스케줄 편집 · 사용자 정보 수정은 소속 관리자 이상. 소속 데이터 수정은 통합 관리자 이상
- 일반 사용자가 비상 해제하면 로봇은 일시정지로 남고, 주행 재개 권한이 없으니 관리자가 개입할 때까지 대기한다 — 의도된 동작

**핵심 규칙**
- 소속 데이터는 단일 출처. 가입 시 소속 필수 선택(드롭다운). 추가 · 리네임은 서비스 오너 · 통합 관리자만. 부서명 중복 불가
- 소속 삭제: 구성원 0명이면 확인 후 삭제, 있으면 '소속 부서 삭제' 모달에서 전원 이동 후 삭제(복구 불가). 상시 '전체 사용자 이동' 버튼 없음. 본인 · 상위 권한이 포함되면 벌크 이동 불가
- 소속 이동 시 권한 유지. 소속 관리자 0명은 정상 상태(통합 관리자가 대신 관리)
- 상위 권한 행은 투명도 30% + 수정 불가로 잠금. 권한 세그먼트는 상위 옵션 Disabled, 로아스 관리자 옵션은 아예 미표시
- 승급 · 강등: 서비스 오너 신규 지정은 서비스 오너 · 로아스 관리자만. 통합 관리자는 서비스 오너 제외. 소속 관리자는 일반 ↔ 소속 관리자만(소속 무관)
- 계정 상태는 활성 / 비활성 2종. **비활성 시 자동 일반 강등**, 재활성해도 복원 안 됨
- 강제 차단: 본인 비활성 · 본인 권한 변경 · 본인 소속 변경 불가 / 마지막 서비스 오너 강등 · 비활성 차단(새 오너 먼저 지정) / 통합 관리자 1 → 0 차단
- 부서 편집 패널: 부서명 · 관리자 지정 토글만(구성원 리스트 읽기 전용, 상태 칼럼 표시). 토글 on/off는 실제 승급 · 강등. 통합 관리자 이상 · 비활성 사용자는 토글 Disabled. 부서 생성은 부서명만 받는 모달, 대시보드 · 진단 표시 항목은 기본 전부 켜짐
- 프로필 설정: 이름 · 직책만 수정, 다른 사용자 화면에 즉시 반영. 비밀번호 재설정은 범위 밖
- 이벤트 로깅(추후 기능): 조치 상태 변경 · 로봇 수동 조작 · 비상 정지 3종. 읽기 전용. 열람은 통합 관리자 이상. 로아스 관리자 조작은 '고객센터 지원'으로 표기
